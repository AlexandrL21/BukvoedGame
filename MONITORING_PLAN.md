# План мониторинга релиза «Буквоед»

## Что отслеживается в игре
Локально в браузере считаются:
- количество запусков;
- количество начатых уровней;
- победы и поражения;
- суммарные ошибки;
- использование Подсказки и Ластика;
- примерное время в игре.

Эти данные не отправляются на сервер автоматически. Это демонстрационный безопасный механизм мониторинга для учебного проекта.

## Отзывы игроков
В игре есть форма обратной связи. Она формирует структурированный текст с версией, категорией, оценкой, типом устройства и номером уровня. Пользователь может скопировать его или открыть форму создания GitHub Issue.

## Как анализировать обратную связь
1. Повторяющиеся баги помечаются как приоритетные.
2. Сложные уровни выявляются по отзывам и высокому числу поражений/ошибок при тестировании.
3. Частое использование Подсказки может указывать на слишком сложные формулировки или большое число отвлекающих букв.
4. Отзывы по мобильному управлению анализируются отдельно от клавиатурного.
5. После исправления проблема повторно проверяется и включается в журнал версии.

## Цикл обновления
Отзыв/статистика → выявление проблемы → исправление → тестирование → изменение версии → публикация в `main` → автоматическое обновление GitHub Pages → повторный мониторинг.
