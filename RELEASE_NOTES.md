# Буквоед — Release Notes


## Версия 1.0.2

### Исправлено
- устранено смешивание старых и новых CSS/JavaScript-файлов после обновления GitHub Pages;
- к `styles.css` и `game.js` добавлен идентификатор версии для принудительного обновления кэша;
- повторно проверена работа кнопок главного меню, статистики, отзыва, справки и настроек;
- версия интерфейса синхронизирована с релизом 1.0.2.

## Версия 1.0.1

Небольшое обновление интерфейса на основе обратной связи после релизной проверки.

### Исправлено и изменено
- кнопки «Статистика» и «Оставить отзыв» перенесены из игровой панели в главное меню;
- панель «Быстрые действия» оставлена только для справки и настроек;
- исправлена ошибка, из-за которой кнопки «Как играть» и «Настройки» в быстрых действиях не открывали окна;
- унифицировано открытие справки, настроек, статистики и обратной связи через общую функцию модальных окон.

## Версия 1.0.0

Первая релизная версия образовательной браузерной игры.

### В релиз вошли
- 20 уровней и 4 зоны библиотеки;
- механика последовательного сбора букв;
- жизни, очки, звёзды, Подсказка и Ластик;
- полноценные анимации Буквоеда;
- главное меню, карта уровней, настройки, помощь и экран результатов;
- адаптация под клавиатуру и сенсорное управление;
- оптимизированный Canvas и автоматическая пауза;
- локальная панель статистики;
- канал обратной связи через GitHub Issues.
